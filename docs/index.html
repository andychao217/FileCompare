终端命令行与 Git 工具生态深度整合

内置 mcdiff (macOS) 与 wincmp (Windows)，在终端中随时唤起，无缝对接 Git 工作流。

# 1. 比较 Excel 表格 (.xlsx/.xlsb/.xls/.csv/.tsv) 与 Word 文档
$ mcdiff sales_2025.xlsx sales_2026.xlsx
$ mcdiff contract_v1.docx contract_v2.docx

# 2. 文本与代码快速对比
$ mcdiff main.rs main_refactored.rs

# 3. 配置为 Git 默认合并与对比工具
$ git config --global diff.tool maccompare
$ git config --global difftool.maccompare.cmd 'mcdiff "" ""'
$ git config --global merge.tool maccompare
$ git config --global mergetool.maccompare.cmd 'mcdiff "" "" -b "" -m ""'
$ git config --global mergetool.maccompare.trustExitCode true
# 1. 比较 Excel 表格与 Word 文档
> wincmp diff sales_2025.xlsx sales_2026.xlsx
> wincmp diff contract_v1.docx contract_v2.docx

# 2. 文本与源码文件比对
> wincmp diff Program.cs Program_v2.cs

# 3. 配置为 Git 默认对比与合并工具
> git config --global diff.tool wincmp
> git config --global difftool.wincmp.cmd "wincmp diff "" """
> git config --global merge.tool wincmp
> git config --global mergetool.wincmp.cmd "wincmp merge "" "" "" """
